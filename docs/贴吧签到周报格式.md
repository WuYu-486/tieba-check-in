# 贴吧签到/水贴周报格式规格

> **文档目的**: 供 AI 复用/修改贴吧周报功能时的完整格式规格
> **实现载体**: `push_mail.py`(同目录, `--weekly` 模式)
> **数据来源**: `tieba-run.log`(签到, `tieba_sign.py` 生成) + `tieba-water.log`(水贴, `tieba_water.py` 生成)
> **水贴吧名映射**: `water_threads.json`(tid→吧名 缓存, 由 `tieba_water.py` 维护)
> **实测版本**: 2026-11-21 部署, 真实日志 dry-run + 实发邮件附件验证通过

## 0. 架构概览

```
tieba_sign.py  (每日 08:05 cron) ──> tieba-run.log   ┐
tieba_water.py (每日 09:05 cron) ──> tieba-water.log ┤
                                                      │ 每周五 22:05 cron
                                                      ▼
             push_mail.py --weekly tieba-run.log --water-log tieba-water.log
                │ 解析双日志 → 统计 → 正文「一、二」+ 附件「三、四」
                │ SMTP 发送(QQ邮箱, 465 SSL, 纯文本正文 + .txt 附件)
                ▼
        发送成功后双日志轮转(log -> log.prev)
```

## 1. 输入: 日志行格式

### 1.1 签到(进入运行总结/经验/签到明细)

```
[YYYY-MM-DD HH:MM:SS] 签到完成: 成功 N, 已签 N, 跳过 N, 失败 N          ← 汇总
[YYYY-MM-DD HH:MM:SS] (i/n) [吧名] 签到成功(+N经验)                     ← 明细(新版)
[YYYY-MM-DD HH:MM:SS] (i/n) [吧名] 签到成功                             ← 明细(旧版)
[YYYY-MM-DD HH:MM:SS] (i/n) [吧名] 跳过(未加入) / 失败: xxx / tbs 失效, 重新获取
```

### 1.2 水贴(进入运行总结/经验/水贴明细)

```
[YYYY-MM-DD HH:MM:SS] 水贴完成: 成功 N 帖, 失败 N 帖, 已完成跳过 N 帖    ← 汇总
[YYYY-MM-DD HH:MM:SS] [tid] 第i/4条 成功(pid=xxx exp+N) 内容='xxx'      ← 明细
```

水贴明细行不含吧名, 解析时用 tid 查 `water_threads.json` 映射; 查不到则直接显示 tid。

### 1.3 解析正则(实现原样)

```python
RE_SIGN_DETAIL  = re.compile(r"^\[([\d\- :]+)\] \((\d+/\d+)\) \[(.+?)\] "
                             r"(签到成功(?:\(\+(\d+)经验\))?|跳过\(未加入\)|失败.*|tbs 失效.*)$")
RE_SIGN_SUMMARY = re.compile(r"^\[([\d\- :]+)\] 签到完成: 成功 (\d+), 已签 (\d+), 跳过 (\d+), 失败 (\d+)$")
RE_WATER_DETAIL  = re.compile(r"^\[([\d\- :]+)\] \[(\d+)\] 第\d+/\d+条 成功\((?:pid=\d+ )?exp\+(\d+)\) 内容='(.*)'$")
RE_WATER_SUMMARY = re.compile(r"^\[([\d\- :]+)\] 水贴完成: 成功 (\d+) 帖, 失败 (\d+) 帖, 已完成跳过 (\d+) 帖$")
```

## 2. 输出: 邮件正文(仅两节)

```
【贴吧签到周报】<日期范围>

一、本周运行总结
----------------------------------------
<签到汇总行们>
<水贴汇总行们(在签到之后)>
(空行)
本周合计: 签到成功 X 次, 失败 Y 次
水贴合计: 成功 X 帖次, 失败 Y 帖次, 已完成跳过 Z 帖次   ← 无水贴数据时显示"本周无水贴记录"
(空行)(空行)
二、各吧本周经验
----------------------------------------
<融合经验行们(按总经验降序)>
(空行)
本周经验总计: N (签到 A + 水贴 B)
```

### 2.1 各吧经验融合行格式

| 情况 | 格式 | 示例 |
|------|------|------|
| 签到+水贴都有 | `[吧名] 签到 A + 水贴 B = 总计` | `[fate] 签到 8 + 水贴 48 = 56` |
| 只有签到 | `[吧名] 签到 A = 总计` | `[bilibili] 签到 8 = 8` |
| 只有水贴 | `[吧名] 水贴 B = 总计` | `[轻音] 水贴 24 = 24` |
| 旧版签到日志无经验 | `[吧名] 签到成功*N(旧日志无经验记录) = 0` | — |

排序: 总经验降序, 同分按吧名。

## 3. 输出: 附件(明细)

- 文件名: `贴吧周报明细_YYYY-MM-DD.txt`(UTF-8, RFC2231 编码文件名)
- 内容:

```
三、签到明细(按时间顺序)
----------------------------------------
<签到明细行们原样, 按时间顺序>

四、水贴明细(按时间顺序)
----------------------------------------
<水贴明细行们原样, 按时间顺序>
```

- 无数据时对应段落写 `(无签到明细)` / `(无水贴明细)`

## 4. 空数据兜底

两个日志均无任何汇总/明细行时, 正文为:
`周报周期内无任何签到/水贴日志!` + `可能定时任务未运行或早已失败, 请检查!`
(日期范围为空, 标题退化为只有【贴吧签到周报】, 无附件)

## 5. 运行机制

### 5.1 调用方式

```bash
# 生产(周五 22:05 cron, 发送+双日志轮转)
python3 push_mail.py --weekly /opt/tieba-sign/tieba-run.log \
    --water-log /opt/tieba-sign/tieba-water.log --subject "贴吧签到周报"

# 预览(打印正文和附件内容, 不发送不轮转)
python3 push_mail.py --weekly tieba-run.log --water-log tieba-water.log --subject test --dry-run
```

### 5.2 日志轮转

- **发送成功后**: 签到日志与水贴日志都重命名为 `.prev`(旧 prev 覆盖删除)
- **发送失败时**: 均不轮转, 数据累积到下一期, 日期范围自动扩展

### 5.3 cron 配置(生产)

```
# 每日签到 + 凭证失效即时告警(退出码2)
5 8 * * * /opt/python/bin/python3 /opt/tieba-sign/tieba_sign.py >> /opt/tieba-sign/cron-run.log 2>&1; [ $? -eq 2 ] && /opt/python/bin/python3 /opt/tieba-sign/push_mail.py --subject "紧急: 贴吧凭证失效" --alert "BDUSS已失效, 请重新获取并更新服务器 /opt/tieba-sign/cookies 文件" >> /opt/tieba-sign/mail.log 2>&1

# 每日水贴 + 异常告警(任意非零退出码: 凭证失效/部分失败/接口异常)
5 9 * * * /opt/python/bin/python3 /opt/tieba-sign/tieba_water.py >> /opt/tieba-sign/water-cron.log 2>&1; rc=$?; [ $rc -ne 0 ] && /opt/python/bin/python3 /opt/tieba-sign/push_mail.py --subject "告警: 贴吧水贴异常" --alert "水贴任务异常退出(退出码 $rc), 请检查服务器 /opt/tieba-sign/tieba-water.log" >> /opt/tieba-sign/mail.log 2>&1

# 每周五 22:05 周报(签到+水贴)
5 22 * * 5 /opt/python/bin/python3 /opt/tieba-sign/push_mail.py --weekly /opt/tieba-sign/tieba-run.log --water-log /opt/tieba-sign/tieba-water.log --subject "贴吧签到周报" >> /opt/tieba-sign/mail.log 2>&1
```

### 5.4 凭证配置(notify.ini, gitignore)

```ini
[smtp]
host = smtp.qq.com
port = 465
user = <发件QQ邮箱>
password = <SMTP授权码>
to = <收件邮箱>
```

## 6. AI 修改指南

| 想改什么 | 动哪里 |
|---------|--------|
| 融合经验行格式 | `fmt_fused_line()` 函数 |
| 正文/附件分段结构 | `build_weekly()` 函数 |
| 识别的日志行 | `RE_SIGN_*` / `RE_WATER_*` 正则 |
| 附件文件名 | `build_weekly()` 调用处的文件名模板 |
| 发送时间 | cron 第5个字段(周几) |
| 轮转策略 | `rotate_log()` 函数 |
| 告警条件 | cron 中的退出码判断 |

注意: 修改后务必 `--dry-run` 验证正文与附件格式; 实发测试请用日志**副本**,
避免测试发送轮转掉生产日志。
