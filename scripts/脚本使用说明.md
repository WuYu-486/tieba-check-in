# 脚本使用说明

> 目录约定: 所有脚本统一放在 `scripts/`; 配置与数据(`deploy.ini`、`water_posts.txt`、`cookies`、`docs/`)在仓库根目录,
> 部署到服务器 `/opt/tieba-sign/` 时脚本与数据平铺在同一目录。
> 本地管理类脚本依赖 `deploy.ini`(SSH 配置) 与 `paramiko`; 服务器脚本纯标准库, 由 cron 调用。

## 一、每日定时任务(服务器 cron)

| 脚本 | 触发时间 | 用途 |
| --- | --- | --- |
| `tieba_sign.py` | 每天 08:05 | 签到所有关注的吧, 日志 `tieba-run.log` |
| `tieba_water.py` | 每天 09:05 | 水贴: 每帖 4 条, 日志 `tieba-water.log` |
| `tieba_autopost.py` | 每天 13:05 | 自动发贴: 按目标发 n 条指定内容, 日志 `tieba-autopost.log` |
| `push_mail.py` | 周五 22:05 | 周报邮件(正文运行总结+经验, 附件明细); 任务失败时发告警 |

```bash
# 手动在服务器执行(一般无需这样用, 管理工具已封装)
/opt/python/bin/python3 /opt/tieba-sign/tieba_water.py --now
/opt/python/bin/python3 /opt/tieba-sign/tieba_autopost.py --now [--dry-run]
/opt/python/bin/python3 /opt/tieba-sign/push_mail.py --weekly tieba-run.log \
    --water-log tieba-water.log --autopost-log tieba-autopost.log \
    --subject test --dry-run
```

## 二、账号与吧管理

### tieba_exp.py — 查询关注吧经验

```bash
python scripts/tieba_exp.py [--sort need|level|name]
```

- 显示每个关注吧的等级、当前经验、距下一级还差多少经验、今日是否已签
- 等级阈值来自 `docs/贴吧各等级经验值.md`, 改表格即改计算口径
- 默认按"还差经验最少"排序; `--sort level` 按等级降序, `--sort name` 按吧名

### tieba_sign_now.py — 立即触发签到

```bash
python scripts/tieba_sign_now.py
```

- 在服务器执行完整的签到流程并透传输出
- 结果写入服务器 `tieba-run.log`, 与每日任务共用并计入周报

### cleanup_forum.py — 清理某个吧的全部目标

```bash
python scripts/cleanup_forum.py <吧名> [更多吧名...]
```

- 删除该吧的水贴目标与自动发贴目标(按水贴缓存中的吧名匹配), 清除对应当日进度与开关状态
- 同步重写本地 `water_posts.txt` 并重建两份目标清单文档
- 只改本项目的配置, 不涉及关注/取关, 已发出的帖子不会撤回

## 三、水贴管理

### add_water.py — 新增水贴目标

```bash
python scripts/add_water.py <帖子URL或tid> [更多...] [--dry-run] [--no-water]
```

- 自动解析帖子所属吧名, 写入服务器与本地列表, 重建清单
- 默认添加后立即补齐今日 4 条; `--no-water` 只添加不发, `--dry-run` 只预览

### water_switch.py — 水贴开关

```bash
python scripts/water_switch.py                     # 查看状态与今日进度
python scripts/water_switch.py on|off <URL或tid>...
```

- 新目标默认开启; 关闭的帖子不参与每日水贴, 当日进度保留; 切换不会立即发贴

### water_delete.py — 删除水贴目标

```bash
python scripts/water_delete.py <帖子URL或tid> [更多...]
```

- 从服务器列表移除, 同时清除当日进度与开关状态, 并重建本地清单

## 四、自动发贴管理

### autopost_manage.py — 目标管理

```bash
python scripts/autopost_manage.py                                           # 查询
python scripts/autopost_manage.py add <URL或tid> --content "内容" [--count N]
python scripts/autopost_manage.py on|off <URL或tid>...
python scripts/autopost_manage.py del <URL或tid>...
```

- 每个目标可单独配置内容与每日条数; 新目标默认开启
- 改动即时写入服务器, 不会立即发贴; 查询结果同步到 `docs/自动发贴目标清单.txt`
